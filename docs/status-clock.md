# 하단바 시계

로컬 연결 상태 오른쪽, 하단바 맨 끝에 현재 날짜·시간을 표시합니다. 기본값은 날짜·요일과 오전/오후 시간을 작은 두 줄로 표시합니다.

시계를 클릭하면 Tippy 설정 드롭다운이 열립니다. 아이콘+시간 / 날짜+시간, 12·24시간제, 초 표시, 요일 표시, 날짜 형식, 컴퓨터 시간대 / 지정 시간대를 선택할 수 있습니다. 지정 시간대는 검색해서 선택합니다. 날짜 없는 모드에서는 날짜 설정을 비활성 처리합니다.

설정은 로컬 표시 환경의 localStorage에 저장하고 기존 표시 모드 설정도 이어받습니다. 날짜·요일·시간은 같은 시간대를 기준으로 계산하고 1초마다 갱신합니다.

검증: 빌드 통과. 내장 브라우저에서 표시 모드 전환, 전체 옵션, 새로고침 후 설정 유지, UTC로 변경했을 때 전날 날짜로 바뀌는 것을 확인했습니다. 확인 후 기본 표시 설정으로 복원했습니다.
