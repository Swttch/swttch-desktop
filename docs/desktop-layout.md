# 데스크탑 셸 레이아웃

> 2026-10-09 Codex 레퍼런스에 맞춰 수정. 사용자 검수 대기. [DESIGN.md](../DESIGN.md)가 최신 시각 기준이다.

상단바와 왼쪽 아이콘 레일을 같은 배경으로 이어주고, 안쪽에 프로젝트·세션 사이드바와 작업 영역을 둔다. 외부 기본 탭바는 제거했다.
Electron은 데스크탑 런타임이고, 바깥 셸 프론트도 React로 구성한다. 기존 React 채팅 웹앱은 독립된 뷰로 유지한다.

## 영역별 책임

| 영역 | 내용 |
|---|---|
| 상단바 | 중간 사이드바 토글, 현재 프로젝트·대화 제목, 새 채팅·프로젝트 열기 |
| 왼쪽 레일 | 작업 공간·프로젝트 열기·세션 목록·새 채팅·계정 상태 |
| 중간 사이드바 | 프로젝트·실제 세션 목록, 검색, 연결 상태·재시도 |
| 오른쪽 작업 영역 | 선택 전 빈 화면, 선택 후 기존 채팅 앱 |

셸 탭은 애플리케이션을 담고, 채팅 앱의 상단바는 대화 세션을 다룬다. 셸에 세션 관리 기능을 중복 구현하지 않는다.
앱 설정·계정 연동은 미구현이며 동작하지 않는 메뉴를 장식으로 배치하지 않는다.

## 배치

- html/body 기본 14px. 상단바 3.25rem(45.5px), 왼쪽 레일 3.5rem(49px). 중간 사이드바 16rem(224px), 800px 이하에서는 14rem(196px).
- 중간 사이드바를 접어도 왼쪽 레일은 유지된다. 단축키는 `⇧⌘S` (Windows·Linux: Ctrl+Shift+S).
- 채팅은 React 작업 영역의 iframe에 담는다. 로컬 프록시로 셸과 같은 origin을 사용하며 Electron·브라우저에서 동일한 배치가 적용된다.
- 프로젝트를 열기 전·후 같은 틀을 유지한다. 안내 화면은 작업 영역 안에서만 표시한다.

이전 레이아웃은 `artifacts/layout-v1/`에 보존했다. 현재 소스는 `renderer/src/App.tsx` 및 `renderer/src/shell.css`다.
