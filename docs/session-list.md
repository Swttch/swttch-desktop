# 프로젝트 상세페이지 세션 목록

플러그인의 `SessionPanelPage`, `SessionList`, `SessionItem`, `useSessionList`,
`useSessionListKeyboard`, `SessionFilterBar`, 날짜·출처 유틸리티를 기준으로 구현한다.
플러그인 소스는 수정하지 않고 기존 Node 백엔드에 위임한다.

- 로컬/웹 범위. 웹은 플러그인과 동일하게 아직 세션 공급자가 없어 빈 안내를 표시한다.
- 새 채팅, 검색 자동 포커스, 검색 지우기. 제목·원본 sessionId·sessionDir 검색.
  대소문자 무시 정규식, 잘못된 정규식은 문자열 검색으로 처리한다.
  검색 시 한 번의 무제한 조회로 아직 로딩하지 않은 세션도 검색한다.
- 일반 목록은 30개씩 조회한다. 원본 total/nextOffset/hasMore를 사용한다.
  스크롤 끝 200px 이내 또는 화면이 채워지지 않으면 다음 페이지를 불러온다.
  더 보기와 실패 재시도도 제공한다. 페이지를 합친 뒤 ID 중복 제거 및 최신순 정렬,
  sidechain 제외는 최종 프론트에서 처리한다.
- 오늘·어제는 로컬 자정, 지난 7일·30일은 경과 시간, 이전 그룹을 사용한다.
  lastTimestamp 우선, 없으면 createdAt. 상대 시간, 제목 말줄임과 전체 제목 Tippy.
- 서버 scopeDirCount가 둘 이상이면 모든 행에 출처를 표시한다.
  기준 프로젝트는 폴더 이름, 하위는 상대 경로, 외부는 전체 경로.
  출처는 제목 위에 표시하며 인라인 수정 중에도 유지한다.
- 인라인 이름 변경: 포커스·전체 선택, Enter/blur 저장, 빈 이름 무시,
  Escape 취소. TanStack Query 캐시를 낙관적으로 갱신하고 실패 시 복구한다.
- 삭제 전 화면 중앙 확인창, 취소 기본 포커스, 진행 중 중복 제출 방지.
  기존 백엔드가 원본 기록 삭제와 관련 정리를 수행한다.
- 열린 세션만 14px 활동 마커 표시. 대기/실행 중/응답 대기/완료,
  실행 중 회전 링. SSE로 원본 백엔드 활동 및 목록 변경을 전달한다.
- 활동 상태 3종과 열린/닫힌 탭의 다중 선택 필터, 활동만 표시.
  카운트는 검색 결과를 기준으로 필터 적용 전에 계산한다.
  빈 선택은 제한 없음, 여러 필터 축은 AND. 메뉴는 Tippy로 body에 표시한다.
- 위/아래 방향키로 목록 이동, 검색창 Enter로 선택, 선택 행 자동 스크롤.
  현재 세션 표시와 키보드 강조를 구분한다. Cmd/Ctrl+Shift+P 새로고침.
- 로딩·오류·연결 준비·검색 없음·필터 결과 없음·세션 없음 구분.
- 상세 헤더의 경로 복사 버튼은 전체 경로를 클립보드에 복사하고 Tippy로만 경로를 표시한다.
- 하위 프로젝트 포함 토글은 includeNestedSessions를 기존 백엔드의 프로젝트 범위 설정에 저장한다.
  병합 대상은 DB의 nullable `projectId` self FK를 따라 찾은 모든 하위 프로젝트다. 경로 계층은 최초 마이그레이션의 자동 연결에만 사용한다.
  활성일 때 DB에 등록된 하위 프로젝트 개수를 표시한다. 드롭다운의 별칭·상대 경로를 선택하면
  해당 프로젝트 ID 상세 라우트로 이동한다. 숨긴 프로젝트와 접두사만 같은 다른 폴더는 제외한다.
  토글 변경은 세션 Query 키를 구분해 이전 범위의 페이지를 섞지 않는다.
- 원본 설정 includeNestedSessions를 먼저 읽은 후 목록을 조회한다.
  열기·이름 변경·삭제는 선택한 세션의 원본 sessionDir를 사용한다.

## 데스크탑 환경 적용

사이드바와 프로젝트 목록 페이지는 같은 프로젝트 Query와 공통 정렬 함수를 사용한다. 고정 프로젝트를 먼저 표시하고, 공유된 최근 사용순·생성순 설정에 따라 정렬한다. 사이드바 프로젝트 클릭은 ID 상세 라우트 이동과 해당 프로젝트의 세션 펼침을 함께 수행하며, 펼침·더 보기 상태는 프로젝트별로 유지한다. 채팅 작업 디렉터리가 선택돼 있지 않아도 세션 목록을 조회한다.

폴더 아이콘은 독립 버튼으로 세션 목록만 펼치거나 접고 라우트를 변경하지 않는다. 이름 클릭은 상세 이동과 펼침을 함께 수행한다. 펼침 상태는 `projects.sessions_expanded` boolean 컬럼(`sessionsExpanded`)에 REST PATCH로 저장하며, 재시작·재가져오기 후에도 유지한다. 기본값은 false이며 SQLite v6에서 기존 DB를 업그레이드한다. UI는 TanStack Query 캐시를 낙관적으로 갱신하고 저장 실패 시 복원한다. 더 보기 상태만 일시적인 UI 상태다.

IDE의 새 에디터 탭 열기는 데스크탑 MVP의 단일 작업 영역에 세션을 여는 것으로
연결한다. 다중 패널이나 새로운 탭 시스템은 추가하지 않는다.
프론트의 REST 조회/변경은 TanStack Query로만 처리한다.
프로젝트 ID 기반 세션 REST 리소스는 공유 API_PATH에 정의한다.

## 검증

`bash ./scripts/build.sh build`, `bash ./scripts/build.sh test`.
REST 테스트는 페이징·원본 필드 보존·설정 적용·중첩 폴더·이름 변경·삭제·읽음·CSRF를 검증한다.
유틸리티 테스트는 정규식 오류·날짜 경계·경로 경계·중복·sidechain·정렬을 검증한다.
구독 테스트는 원본 활동 이벤트 전달·재연결·종료 후 자원 정리를 검증한다.
Codex 브라우저에서는 실제 로컬 세션 검색, 필터, 페이지 추가 로딩,
이름 변경/원복, Escape 취소, 삭제창 취소 및 중앙 배치,
방향키/Enter로 하위 프로젝트 세션 열기를 확인한다.
