# 실행·복구 정책과 검증

> 2026-10-11. macOS 로컬 소스 실행에서 검증했습니다. 설치 패키지·Windows·Linux 검증은 별도입니다.

## 적용 동작

- 앱 시작 시 로컬 호스트를 실행하고 CCG를 준비합니다. 인증 가능한 기존 CCG는 재사용합니다.
- 창 닫기와 Cmd+Q는 같은 종료 확인창을 표시합니다. 취소하면 창과 대화가 유지됩니다.
- 종료하면 앱의 로컬 호스트와 앱이 직접 실행한 CCG를 정리합니다. 별도로 실행한 CCG는 유지합니다. 열린 WebSocket도 종료하므로 탭이 닫힐 때까지 호스트 종료를 기다리지 않습니다.
- SQLite v10의 `workspaces`에 마지막 데스크탑 프로젝트 ID와 세션 UID를 저장합니다. 인증 코드·토큰·프롬프트는 저장하지 않습니다. 재실행 시 새 인증 코드로 같은 대화를 엽니다. 브라우저 클라이언트는 각자의 작업 뷰를 유지합니다.
- 새 세션 UID는 세션 생성과 소스 등록을 기다려 저장합니다. 숨겨진 프로젝트는 복원하지 않습니다. 없어진 폴더·세션은 오류를 표시하며 다른 프로젝트·세션을 선택할 수 있습니다.
- 연결이 끊기면 상태를 표시하고 WebSocket 연결을 자동 재시도합니다. 연결 오류만으로 살아 있는 CCG를 종료하거나 새 프로세스를 생성하지 않습니다.
- 종료된 CCG는 사용자가 ‘재시도’를 선택하면 다시 실행합니다. 인증 실패·다른 서비스의 포트 점유·실행 파일 누락은 오류로 표시합니다. 임의로 기존 프로세스를 종료하지 않습니다.
- 앱 소유 로컬 호스트가 종료되면 ‘다시 연결’ 또는 ‘종료’를 선택하는 네이티브 안내를 표시합니다. 다시 연결하면 호스트를 재실행하고 마지막 저장 대화를 엽니다. 재실행 실패는 오류로 표시하며 자동 재시작을 반복하지 않습니다.
- 대화 복원과 작업 재개는 구분합니다. 중단된 CLI 작업이나 이전 프롬프트를 자동으로 실행·재전송하지 않습니다. 사용자가 대화를 보고 다음 요청을 보냅니다.

## 실제 검증

| 항목 | 관찰 결과 |
| --- | --- |
| Electron 프로젝트·새 세션 | 프로젝트 선택 후 새 세션에서 `SWTTCH_NATIVE_NEW_OK`, `SWTTCH_RESTORE_OK` 응답 완료 |
| Electron 기존 세션 | 기존 대화 진입, 이전 응답 표시, 새 요청의 `SWTTCH_RESUME_OK` 응답 완료 |
| 창 닫기·앱 종료 | 닫기 버튼 확인창 → 계속 작업 시 유지, 종료 시 정리. Cmd+Q도 동일한 확인창 |
| 재실행 | 53178 → 53727 포트 변경에서 기존 세션 복원. 새 세션 66a2cd19-383c-4b7c-b8c6-54224ed0735c도 55517 → 56002에서 복원 |
| 로컬 호스트 종료·복구 | SIGTERM 정상 정리 후 안내, 다시 연결 선택 → 56208에서 마지막 새 세션과 응답 복원 |
| CCG 종료·복구 | 격리된 실제 CCG(19837) 종료 → 브라우저 연결 종료 표시 → 재시도 → 같은 대화에서 `SWTTCH_RECOVERY_OK` 응답 완료 |
| 독립 CCG 보존 | 기존 19836 CCG PID 13415가 모든 Electron 종료·복구 후에도 동일하게 유지됨 |
| 앱 소유 CCG 정리 | 기존 Electron 소유권 검증 및 이번 격리 호스트 종료에서 소유 런타임 정리 확인 |
| 연속 전환 | 기존 두 세션을 왕복하여 URL과 대화 내용 일치 확인 |

검증은 실제 UI의 클릭·입력 경로로 진행했습니다. 일반 UI에 자동화용 상태 주입이나 우회 API를 추가하지 않았습니다. 검증용 앱 데이터와 CCG는 따로 실행하고 정리했으며 사용자 브라우저·CCG는 유지했습니다.

## 발견한 오류와 회귀 검증

- 브라우저 호스트와 Electron 호스트의 동시 SQLite 활동 갱신에서 `SQLITE_BUSY_SNAPSHOT`이 발생했습니다. 쓰기 트랜잭션을 `immediate`로 변경하고 두 Worker가 같은 DB의 50개 세션 상태를 각각 100회 갱신해 원본 필드와 행 수가 유지되는 것을 검사합니다.
- 닫기 전에 창이 파괴되어 종료 확인을 생략하던 동작을 수정했습니다.
- 포트마다 다른 브라우저 저장 공간 때문에 마지막 대화를 복원하지 못하던 동작을 DB 참조 저장으로 수정했습니다. 사이드바 너비·접힘 같은 origin별 UI 설정의 전체 복원은 이 검증에 포함하지 않습니다.
- 열린 WebSocket이 호스트 종료를 지연시키던 문제를 수정하고 WebSocket 클라이언트가 열린 채로 정상 정리가 완료되는지 검사합니다.
- CCG 종료와 재연결 상태 전달, dispose 이후 재연결 중지, 기존 인증 서버의 반복 연결·비소유 종료 보존을 검사합니다.

빌드 및 테스트 46개 통과. 설치 산출물, OS 강제 종료·전원 중단, 장시간 네트워크 장애와 작업 재개 UX의 추가 정책은 검증 범위 밖입니다.
